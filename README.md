# Valod Translator

Traducteur vocal en temps réel pour Discord.

## Fonctionnalités

- Capture uniquement l'audio de Discord
- Traduction en temps réel
- Espagnol → Français
- Français → Espagnol
- Anglais → Français
- Français → Anglais

## Télécharger

Rendez-vous dans la section Releases pour télécharger la dernière version.

## Compatibilité

- Windows 11 x64
- GPU NVIDIA recommandé
